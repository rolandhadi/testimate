Project Configuration

Rates follow industry-standard per-step estimation. Simple (short flows), Medium (multi-step flows), Complex (large E2E with heavy integration). Clustering discount reduces cost when test cases share setup / libraries. Risk buffer adds contingency for uncertainty.

Advanced Industry Factors (click to expand)

Industry-recommended factors beyond the core step-based rate: Test Data (+10-20% typical), Platform Matrix (e.g. 1.3-1.5x for 2 browsers, 1.5-2x for mobile multi-device), Learning Curve (+15-30% when the team is new to the tool), Framework Setup Uplift (first-time-on-product projects deserve +50-100% on environment and library items), Maintenance (20-30% of dev effort per year, ongoing). PERT (Expected = (O + 4M + P) / 6) gives a risk-adjusted view across best/expected/worst cases.
